# Tarek.Dev Portfolio & Admin Panel 🚀

منصة برمجية متكاملة لإدارة وعرض الأعمال الشخصية مع لوحة تحكم تفاعلية متصلة بسيرفر سحابي.

## 🛠 التقنيات المستخدمة (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Deployment:** Vercel (Frontend) & Render (Backend)

## 📌 مميزات المشروع
* واجهة مستعرضة لعرض المشاريع والمهارات.
* لوحة تحكم لإدارة الرسائل والبيانات.
* اتصال ديناميكي بين السيرفر المحلي والسحابي.
